論文 / 001

          
 Presented · IEEE CoG 2026 · Madrid

        

        

          
RIDGE: State-Conditioned Reward Blending for Behavioral Coverage in Deep RL Game Agents

          
AL Muqshith Mohammed Shifan · Kevin Christopher Chua · Ali Neshati · Loutfouz Zaman · Cristiano Politowski

          

            One PPO agent blends four persona rewards: Explorer, Survivor, Craftsman, and Warrior. The game state sets the blend. The agent changes its play style in one episode. This removes the need to train one agent for each persona. A multi-head critic keeps each value function stable while the blend changes. RIDGE is the only condition that reaches both wood-tier crafting branches on Crafter.

論文 / 002

          
 Draft · Systematic Mapping Study

        

        

          
Emotional Memory in LLM-Driven Non-Player Characters: A Systematic Mapping Study

          
In progress · 66 records screened · 30 primary studies

          

            The standard memory stream for LLM agents ranks past events by recency, importance, and relevance. It does not use emotion. Psychology shows that emotion controls what we keep and what we recall. This study asks two questions. Do LLM NPCs link a stored emotion to a memory? Is that link based on a psychological method? Only 3 of 30 studies do both.
          

          

             Request Preprint
          

        

      

    


    
    

      
01
Persona Stability Inside the Model
Keep authored traits stable at the activation level, not in the prompt. Small models that can run inside a game.

      
02
Emotion-Grounded NPC Memory
A believable NPC must recall the past across a full game. Emotion is the index that decides when a memory is available. Emotion is also a value that the game can write.

      
03
Playtesting Agents With Range
One agent, many play styles. One policy gives behavioural coverage. There is no need for one agent for each persona.
